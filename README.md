## Adriano Souza

Full stack developer from Belo Horizonte, Brazil.

I build and run production systems end to end: Node.js/TypeScript APIs, React web apps, React Native apps on both stores, PostgreSQL, and infrastructure on AWS and DigitalOcean. Most of my work is turning a messy real-world process into software people rely on every day.

**Stack:** TypeScript · Node.js · AdonisJS · NestJS · React · React Native · PostgreSQL · Docker · AWS · Java/Spring · Python

**Some public work**
- [espaco-construir](https://github.com/Dev-Adrianoo/espaco-construir-backend) · scheduling and class tracking platform for a tutoring business, with role-based access for teachers and parents (Spring Boot, PostgreSQL, React)
- [CircuitNode](https://github.com/Dev-Adrianoo/CircuitNode) · browser-based electronics lab that simulates circuits and generates Arduino C++ (React Flow, Node/TS, Docker)
- [lumina-agent](https://github.com/Dev-Adrianoo/lumina-agent) · voice-driven dev assistant with an action gate that keeps casual speech from triggering commands (Python, 161 tests)

On the side: XR on Meta Quest 3 ([LuminaXR](https://github.com/Dev-Adrianoo/LuminaXR)).
